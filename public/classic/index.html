JARVIS AI Voice Assistant

AI project

A voice-based personal AI assistant inspired by Iron Man's JARVIS, built with React, Node.js and the Google Gemini API. You talk or type, it answers, and it remembers facts across sessions.

Select a part of the system to see what it does.

A React 18 and Vite front end with Zustand for state and Framer Motion for animation. It draws the holographic heads-up display and handles speech input and output through the browser's Web Speech API.

An Express REST API organized as routes, controllers and services across five modules: AI, memory, settings, voice and system. Helmet headers, rate limiting and request validation protect it, and the API key stays on the server.

Google Gemini (gemini-2.5-flash) writes each reply from the recent chat history and the facts the assistant has stored about you.

SQLite, running through sql.js, stores sessions, messages, memory and settings. The data persists across restarts, so the assistant continues where it left off.

Objective

A personal assistant you can speak to hands-free, that answers with a language model and keeps its memory between sessions.

How it works

The interface sends your text, or your transcribed speech, to the Express API. The API adds chat history and stored memory, asks Gemini for a reply, saves the exchange in SQLite and returns the answer to be shown and spoken.

Key features

  • Speech input and output in the browser
  • Memory that persists across sessions
  • Five backend modules with a clean service layer
  • Rate limiting, validation and secured API keys

What it covers

The paper's four-phase landing model

  1. Above 70 km

    Boostback burn

    Reverses toward the landing zone.

    Sensors: GPS, inertial unit. Actuators: engine gimbal, cold-gas thrusters.

  2. 70 to 30 km

    Entry burn

    Slows the booster in the upper atmosphere.

    Sensors: GPS, inertial unit. Actuators: grid fins, engine gimbal.

  3. 30 to 3 km

    Aerodynamic descent

    Unpowered glide steered by grid fins.

    Sensors: GPS, inertial unit, radar altimeter. Actuators: grid fins.

  4. 3 km to touchdown

    Landing burn

    PID-controlled powered deceleration. The simulation at the top of this page is a simplified version of this phase.

    Sensors: radar altimeter, inertial unit. Actuators: engine gimbal, cold-gas thrusters.
